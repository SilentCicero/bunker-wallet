# Non-UI TypeScript integrity checks

These tests exercise public/disposable vectors and invalid inputs. They are not a cryptographic audit. UI components and generated bytecode/artifacts are excluded.

| Module                                                          | Unit/integration checks                                                                                                                                                                        |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/core`                                                 | Merkle root/vector, 20 proofs and tampering, domain/chain/version, owner/sequence/index/bigint boundaries, transfer intent limits.                                                             |
| `packages/safe/{index,hybrid,experimental}`                     | Exact named runtime-codehash pins, Safe/chain/version bindings, ECDSA low-s and framing, sorted dual signatures, hybrid and experimental digest mutations.                                     |
| `packages/offline`                                              | Canonical envelope roundtrip; wrong runtime types, nonce/value/uint256, malformed/oversized JSON, ownership, refund and proof framing. Checksums are tamper detection, **not authentication**. |
| `packages/vault`                                                | BIP-39, Argon2id parameter bounds, AES-GCM roundtrip/tamper, password, metadata and authenticated-data mutations. Browser compromise still defeats the vault.                                  |
| `packages/pq/src/keys`                                          | HKDF separation and path limits, real ML-DSA KeyGen/blob/public signature vector, C10 Rust/Python/WASM fixture and error boundaries. Browser KeyGen provenance is not proven on-chain.         |
| `apps/web/src/{burner,activity}`                                | Disposable BIP-32 derivation vector/index limits, ENS/recipient/balance bounds and activity checks.                                                                                            |
| `apps/web/src/pq/{config,outbox,signer,wallet}`                 | Exact isolated-host gating, outbox AEAD identity/AAD/tamper checks, malformed and stale worker messages/signature framing, checkpoint/runtime immutables and data-code limits.                 |
| `apps/web/src/pq/signer.worker`, `apps/web/src/unlockedSession` | Exercised through disposable-Anvil PQ signing/browser persistence lifecycle suites; browser workers and IndexedDB are **not** represented by fake Bun unit implementations.                    |
| `apps/relayer`                                                  | Loopback-only HTTP health, bounded envelope acceptance/rejection, rate limit and explicit no-broadcast behavior.                                                                               |
| Operational `scripts/`                                          | Build, release verification and Anvil/browser flows are integration-tested where run; live Sepolia broadcast scripts remain explicitly gated and are **not** unit-tested or run in CI.         |

Run `bun test`, `bun run typecheck`, `bun run contract:test`, the disposable-Anvil browser runners, and `bun run release:verify`. Runtime guards and Safe verification remain separate from these client-side checks; a passing suite cannot establish exploit resistance or replace independent security review.
