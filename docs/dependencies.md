# Dependencies

Direct runtime dependencies are SolidJS, viem, pinned Scure/Noble primitives (including unaudited-in-this-wallet Noble post-quantum), and official Safe 1.4.1 contracts. Vite and TypeScript are development dependencies. External versions are exact and `bun.lock` is committed; `workspace:*` references only private local packages. No lifecycle package is trusted in `package.json`. Run `bun run dependency:report` and `bun audit` before release. Cryptographic, Safe, hardware, and signing dependency changes require manual security review. See the [dependency and supply-chain review](dependency-security-review.md) for tested pins, advisories and limitations.
