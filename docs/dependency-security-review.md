# Dependency and supply-chain review (Sepolia-only)

Scope: root and workspace npm manifests, `bun.lock`, C10 `Cargo.toml`/`Cargo.lock`, Foundry projects, vendored Safe/PQ verifier code, CI actions and install/build scripts. This is a source/configuration and known-advisory check, **not** an independent audit or a guarantee against compromised releases.

| Surface | Pin and check | Remaining risk |
| --- | --- | --- |
| Runtime npm | Exact `@noble/hashes@2.4.0`, `@noble/post-quantum@0.7.1`, `@scure/bip39@2.4.0`, `solid-js@1.9.17`, `viem@2.57.3`; all transitives locked with integrity hashes in `bun.lock`. `bun install --frozen-lockfile` and `bun audit` pass with no reported advisories. | A published package with valid registry integrity can still contain malicious or flawed code; Noble PQ and wallet integration are not independently audited here. |
| Dev npm | Exact `@playwright/test@1.63.0`, `@types/bun@1.4.2`, `solc@0.8.24`, `typescript@5.9.3`, `vite@8.3.3`, `vite-plugin-solid@2.11.14`; CI installs with frozen lockfile. | Dev/build dependencies execute on trusted build machines. Avoid unreviewed upgrades and compromised build environments. Vite 8.3.3 includes fixes for [GHSA-rq7h-c2jc-7f22](https://github.com/vitejs/vite/security/advisories/GHSA-rq7h-c2jc-7f22) and [GHSA-9jrq-w75r-8gcw](https://github.com/vitejs/vite/security/advisories/GHSA-9jrq-w75r-8gcw). |
| Local workspaces | `workspace:*` resolves only to the private in-repository `@bunker/*` packages; it is **not** a floating external registry dependency. | Workspace source changes still require review. `trustedDependencies` is empty, so dependency lifecycle scripts are not explicitly trusted. |
| C10 Rust | `tiny-keccak = "=2.0.2"`; `Cargo.lock` locks transitive `crunchy@0.2.4` and both checksums. `cargo metadata --locked` and `cargo test --release --locked` pass. | `cargo-audit`/OSV scanner was not installed; no Rust-advisory database scan was run. Registry checksum attests package bytes, not author intent. |
| Solidity and vendored cryptography | Foundry projects pin solc `0.8.24` or `0.8.30` and compiler options. Official Safe 1.4.1, C10 and Fireblocks ML-DSA sources and helper are committed; runtime codehash checks bind critical dependencies. | Vendoring and pinned hashes do not prove Safe/crypto correctness or honest browser KeyGen/ML-DSA prepared-blob provenance; independent review remains required. |
| CI runner and actions | `ubuntu-24.04`; checkout, setup-bun and Foundry toolchain actions pinned to full commits from their official `v4`, `v2`, `v1` tags. Bun `1.3.14`, Foundry `v1.8.5`, frozen install. | The Ubuntu image and toolchain release artifacts can change independently of the action commit; rerun checks and review upgrades. |

Direct package versions already were exact; no blanket dependency upgrades were made merely to clear a scanner. `bun audit` covers known npm advisories at query time; manual inspection and these tests cannot detect all zero-days, dependency confusion, compromised maintainers or build-time substitutions. See [contract test matrix](contract-test-matrix.md), [dependency policy](dependencies.md), and [security status](../SECURITY_STATUS.md).
